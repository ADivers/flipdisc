A single disc in a black ring, followed by a status word — the system's only pictogram.

**Provide** `state` (`on` white, `off` black, `alert` orange) and `children` (the status word, always).

**Do**
- Use in tables, panel headers and footers: "On time", "Delayed", "Offline".

**Don't**
- Don't use the disc without its word; the colour alone carries no meaning.
