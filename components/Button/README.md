Square-cornered action button: orange primary, outlined secondary, and ghost.

**Provide** `children` (a short verb phrase), `variant` (`primary` default, `secondary`, `ghost`), optional `size="sm"`, `dot` for a leading disc, and `href` to render a link.

**Do**
- One primary per view — it is the orange signal.
- Use sentence case: "Get started", "View schedule".

**Don't**
- Don't put a primary on an orange block.
- Don't add icons; use `dot` if the button needs a mark.

The primary flips from `orange-500` to `ink` on hover. All variants show the 2px `focus` ring.
